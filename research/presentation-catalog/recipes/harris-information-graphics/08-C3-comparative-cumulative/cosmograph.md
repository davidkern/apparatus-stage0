## Description

A cosmograph shows how equal inputs and outputs are distributed, revealing the flow from sources to destinations. The total value on the input side (typically left) equals the total value on the output side (typically right), with flowing bands or ribbons showing how each input category contributes to each output category.

This visualization is particularly effective for showing budget flows, where money received from various sources is allocated to different expenditure categories.

## Examples

Harris illustrates two cosmograph variations on page 112:

> Cosmographs where total input on left equals total output on right.

**Government/company budget example:**
- Input (left): 29% Other taxes/fees/licenses, 26% Income taxes, 18% Sales taxes, 12% Federal funds, 15% Vehicle taxes
- Output (right): 32% Education, 22% Health & Welfare, 19% Roads and highways, 15% Operating expenses, 12% Corrections, etc.
- Total income equals total expenditures

**Product/profit example:**
- Input (left): Product A sales 40%, Product B sales 20%, Product C sales 30%, Miscellaneous income 10%
- Output (right): Cost to manufacture 70%, Engineering 5%, Marketing 10%, Administrative 5%, Profit 10%
- Income equals Expenditures and profit

## Usage

Cosmographs are most effective when:
- Showing budget or resource allocation
- Demonstrating how revenue sources fund expenditure categories
- The total input must equal total output
- Viewers need to understand the overall flow structure

Values can be expressed in:
- Absolute units (dollars, quantities)
- Percentages
- Any unit of measure where input totals match output totals

The visualization reveals:
- Relative size of each input source
- Relative size of each output destination
- How inputs flow to outputs (when connection bands are shown)

## Notes

Harris notes that cosmographs were originally generated by arranging mechanical models and then photographing them. Modern software can generate similar visualizations, now often called Sankey diagrams or alluvial plots when showing the flow connections between inputs and outputs.
