## Description

A template chart or graph contains all or most of the common elements of a series of charts or graphs. Detailed information is then added to copies of the template to form specific variations. Templates enable rapid construction, facilitate revision, improve accuracy, and create consistency across a series of charts. They are frequently used as backgrounds for presentation charts to provide uniform appearance throughout a presentation.

## Examples

### Sales Performance Template (p. 397)

Harris illustrates with a sales tracking example:

**Template contains**:
- Y-axis: "Sales in $ millions" with scale 0-20
- X-axis: Years '91-'95
- Chart frame and grid structure
- Title area placeholder

**Three variations generated**:
1. Salesperson A's performance (specific column data added)
2. Salesperson B's performance (different column data)
3. Salesperson C's performance (different column data)

> "These three graphs were generated by adding specific information to the template at the left." (p. 397)

### Flexibility in Application

> "In the example, the three specific charts generated from the template are all column graphs. It is not required that they all be the same, nor is there a restriction as to the type of chart or graph that can be generated using templates." (p. 397)

This flexibility means a single template might generate column graphs for some data, line graphs for others, or combination charts as appropriate to the specific content.

## Usage

### When to use templates

**Presentation series**: Multiple charts need consistent appearance throughout a presentation or report.

**Repetitive reporting**: Regular reports (monthly sales, quarterly performance) use same structure with updated data.

**Comparative analysis**: Same framework applied to different entities (departments, products, regions) for direct comparison.

**Organizational standards**: Company-wide chart specifications enforced through shared templates.

### Template elements to standardize

- Axis scales and labels
- Chart dimensions and proportions
- Color schemes and patterns
- Font selections and sizes
- Grid line styles
- Frame appearance
- Title and legend placement
- Logo or branding elements

### Construction approach

1. Identify common elements across planned chart series
2. Create master template with all shared features
3. Leave data areas blank or with placeholder indicators
4. Generate copies for each specific chart
5. Add unique data and any variation-specific elements

### Revision benefits

When common elements need updating (e.g., changing scale, updating branding), modify the template and regenerate affected charts rather than editing each individually.

## Notes

Templates represent a production efficiency technique rather than a visualization type. The concept applies to any chart or graph type. Harris emphasizes that templates serve both quality purposes (accuracy, consistency) and efficiency purposes (rapid construction, easier revision).

The note that generated charts need not all be the same type is significant: templates define the frame and common elements, but the specific data visualization approach can vary based on what best communicates each dataset.
