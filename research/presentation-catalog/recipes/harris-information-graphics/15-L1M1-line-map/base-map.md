## Description

Most statistical and descriptive maps are generated by superimposing attribute information on a base map. The base map provides the geographic reference frame while the attribute data provides the information being communicated.

There are no strict guidelines for what belongs in the base map versus the attribute layer. As a general rule, base map information should be minimal to avoid distracting from the attribute data being displayed.

## Examples

**Map composition** (p. 233):
Harris illustrates the concept with Australia:
- Base map (with natural and man-made features) + Attribute information (proportional symbols) = Statistical map

The base map shows state/territory boundaries and coastlines. The attribute information shows symbols of different sizes representing values by region.

**Natural geographic features** (p. 233):
> "Included in the definition of natural geographic features are such things as the outlines of natural land areas (coastlines) and the location of rivers, mountain ranges, lakes, islands, etc."

**Man-made geographic features** (p. 233):
> "Included in the definition of man-made geographic features are such things as political boundaries (cities, states, countries, etc.), postal zones (ZIP codes), trading areas, census regions, school districts, etc."

**Polygon definition** (p. 233):
> "Many of the representations of man-made features such as countries, states, territories, or counties are designated by outlining an area with lines. The graphic unit that is formed by this process is called a polygon."

A polygon can be made of straight or curved lines with any number of sides.

## Usage

Design base maps by:
1. Identifying what geographic reference viewers need
2. Including only features germane to the map's purpose
3. Keeping visual weight low so attribute data stands out
4. Using appropriate detail level for the map scale

Common base map configurations:
- Coastlines only (for continental displays)
- Coastlines + political boundaries (for regional comparisons)
- Coastlines + boundaries + major features (for detailed reference)

## Notes

The distinction between base map and attribute data is context-dependent. Roads might be base map features on a population density map but attribute data on a transportation infrastructure map. The key is supporting the primary purpose without visual competition.
