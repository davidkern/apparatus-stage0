## Description

A patch graph is generated by removing the sides of the columns on a column graph. Patch graphs basically function the same as column graphs, with the added feature that hidden data is sometimes more visible.

Many variations are possible using projections and drop lines.

## Examples

Harris illustrates extensive variations (p. 269):

**Basic comparison:**
- Column graph for reference (with solid 3D columns)
- Same data with sides removed and shading added to tops (patch graph)

**Projection variations:**
- Patches only (no projection)
- Projected onto ceiling
- Projected onto floor

**Drop line combinations:**
- Drop lines to the floor and one wall
- Drop lines and projection on the floor
- Drop lines to grid and projection onto ceiling
- Drop lines to wall and projection onto ceiling

**Multiple data series in single plane:**
> "In some cases the multiple data series can be displayed in one plane so all data graphics touch the back surface with the grid lines. In this way it is sometimes easier to determine which data graphics are in the same categories (e.g., A thru G) and to estimate each of their values."

## Usage

**When to use:**
- When three-dimensional column graphs have hidden data
- When you need to see values that would otherwise be obscured
- When projections or drop lines would aid value estimation

**Variations to consider:**
- Patches only: Simplest form, maximum visibility
- Projections: Help connect values to reference grid
- Drop lines: Provide visual anchoring to axes or walls
- Single-plane arrangement: All data series touch back surface with grid lines

## Notes

The patch graph is essentially a transparency technique for 3D column graphs. By removing solid sides, data that would be hidden behind front columns becomes visible.
