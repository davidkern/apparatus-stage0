## Description

Percentile graphs are sometimes thought of as a subcategory of probability graphs. The term percentile graph refers more to how a graph is used than it does to a specific type of graph.

When used for percentile purposes, the graph provides a graphical means for determining the percent of data elements in a data set that are above or below a certain value - for example, the percentage of people in Wyoming with incomes less than $25,000, or the percentage of athletes taller than six feet.

## Examples

Harris illustrates four types of percentile graphs (p. 271):

**Cumulative frequency graph:**
- Sometimes referred to as cumulative frequency percent, cumulative relative frequency, or ogive graph
- Generated by grouping data into class intervals (as with histogram), counting elements in each interval, and cumulating the counts
- Counts can be cumulated smallest to largest or largest to smallest
- Used to display percentile rankings and determine if data has normal distribution

**Quantile graph:**
- Individual data elements plotted (not class intervals)
- Quantile values or percentiles (100 times quantile value) on horizontal axis
- Value of data element on vertical axis
- Data generally cumulated from smallest to largest value

**Box graph or box plot:**
- Several variations; some referred to as percentile plots
- Most show only popular percentiles: 10, 25, 50, 75, 90
- Disadvantage: cannot determine percentiles for every value
- Example shows individual points, 90th/95th percentile, 75th (upper quartile), mean, 50th (median), 25th (lower quartile), 10th/5th percentile

**Cumulative histogram:**
- Used less frequently for percentile applications
- To determine percentiles for values between class interval boundaries, must interpolate

## Usage

**Choosing a graph type:**
The type of graph chosen for a particular application is subjective and depends on:
- The nature of the data
- The purpose of the graph

**Cumulative frequency graphs:**
- Good for grouped data
- Show smooth curve for easy reading
- Can determine percentiles for any value

**Quantile graphs:**
- Plot individual data elements
- Good when individual values matter
- Clear relationship between value and percentile

**Box plots:**
- Quick summary of distribution
- Limited to selected percentiles
- Cannot read arbitrary percentile values

## Notes

The choice between these graph types depends on whether you need to show every data point (quantile), summarize grouped data (cumulative frequency), provide a quick summary (box plot), or work with existing histogram data (cumulative histogram).
