## Description

This sub-topic (treated by Aristotle as part of Topic 4) handles cases where neither more nor less applies - the comparison is between equivalent cases. If something was judged true (or permissible, or praiseworthy) in one case, it should be judged the same in a parallel case.

This is argument from precedent or analogy. The power lies in the implicit premise that like cases should be treated alike.

## Examples

> "Further, [there is a related form of argument] if [something is] neither more nor less." (1397b27)

Aristotle introduces this as a variant of the more-and-less topic.

> "Your father is pitiable for having lost his children; / Is Oeneus not also then, for having lost a famous offspring?" (1397b28-30)

From a play about Meleager. If one father deserves pity for losing children, so does another in the same situation.

> "[The argument] that if Theseus did no wrong [in abducting Helen], neither did Alexander [Paris]; and if not the sons of Tyndareus [who abducted women], then not Alexander; and if Hector [did no wrong in killing] Patroclus, Alexander also [did no wrong in killing] Achilles." (1397b30-1398a1)

A chain of mythological precedents defending Paris's actions. Each parallel case establishes that if one hero's action was acceptable, the analogous action should be too.

> "And if other professionals are not contemptible, neither are philosophers. And if generals are not contemptible because they are often put to death, neither are sophists." (1398a1-3)

Professional analogies: if one profession is respected despite certain features (risk of death for generals), parallel professions sharing those features should be too.

> "[The argument] that 'if a private individual should care about your reputation, you should care about that of Greece.'" (1398a3-4)

Political analogy: what holds at the individual level should hold at the city-state level.

## Usage

Use this topic when:
- A clear precedent exists
- The current case is genuinely parallel to the precedent
- The precedent's judgment is accepted or can be established

The examples show multiple domains for precedents:
- **Mythological**: Heroes, gods, legendary events
- **Historical**: Past political decisions, legal judgments
- **Professional**: What is accepted for one profession
- **Scalar**: What holds for individuals vs. groups

Multiple precedents (as in the Paris defense) create cumulative force - if the parallel fails in one case, others may still hold.

## Notes

Kennedy's translation notes that this "would seem to deserve to be a distinct topic, though editors and translators do not so treat it." The distinction from Topic 4 proper is that here the cases are equivalent, not ranked as more or less likely.

The mythological examples show how shared cultural knowledge provides a rich source of precedents for rhetorical argument.
