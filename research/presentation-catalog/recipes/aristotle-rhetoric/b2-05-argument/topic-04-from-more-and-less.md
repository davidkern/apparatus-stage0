## Description

The fourth common topic argues from the more and the less (mallon kai hētton). The structure is:
- If something is NOT true where it would be MORE expected, it is not true where it would be LESS expected
- If something IS true where it would be LESS expected, it is true where it would be MORE expected

This is the classical a fortiori ("from the stronger") argument form. The speaker establishes what is true in a case where the predicate more strongly applies (or fails to apply), then draws the inference for the less strong case.

## Examples

> "If not even the gods know everything, human beings can hardly do so." (1397b13-14)

If even gods (where knowledge is MORE expected) don't know everything, then humans (where knowledge is LESS expected) certainly don't.

> "For this is equivalent [to saying,] 'If something is not the fact where it would be more [expected], it is clear that it is not a fact where it would be less.'" (1397b14-16)

Aristotle makes the logical structure explicit.

> "[The argument] that 'a person who has beaten his father has also beaten his neighbors' follows from [the proposition that] if the lesser thing is true, the greater is also; for people strike their father less than their neighbors." (1397b17-20)

The inverse form: if someone has done what is LESS expected (beating his father - a more serious transgression people usually avoid), he has certainly done what is MORE expected (beating neighbors - a lesser transgression).

Aristotle then notes:

> "Or [one can argue] as follows: either 'if something is not the fact in a case where it would be more [expected, etc.]' or 'if in a case where it would be less [expected, etc.],' according to whichever there is need to show, whether that something is or is not the fact." (1397b20-23)

The argument form is flexible - use whichever direction serves your purpose.

## Usage

Two primary argument forms:

**From the stronger (a fortiori):**
- If X doesn't hold where it's more expected, X doesn't hold where it's less expected
- Example: If gods don't know everything, humans certainly don't

**From the lesser (a minore):**
- If X holds where it's less expected, X holds where it's more expected
- Example: If he beat his father, he certainly beat his neighbors

Choose the form based on what you need to establish and what you can demonstrate.

## Notes

This topic is closely related to Topic 4a (from analogy/precedent), which handles cases where neither more nor less applies - the cases are equivalent. Aristotle's numbering places them together as variations on comparative reasoning.
