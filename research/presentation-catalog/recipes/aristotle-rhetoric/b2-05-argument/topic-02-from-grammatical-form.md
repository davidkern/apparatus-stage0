## Description

The second common topic instructs the speaker to examine different grammatical forms (ptōseis) of the same word. If a predicate is true of one form, it should be true of related forms - or the inconsistency reveals a problem with the original claim.

Greek has extensive grammatical inflection, so different "cases" or forms of a word (noun, adjective, adverb, verb forms) can be examined for consistency. The topic tests whether what is said of one form holds for others.

## Examples

> "Another is from [different] grammatical forms of the same word; for the same [predicate] should be true or not true; for example, [to say] that the just is not entirely good; for then what is done justly would be a good, but as it is, to be put to death justly is not desirable." (1397a23-27)

The example demonstrates the topic by showing a problem:
- Claim: "The just is good"
- Test: If so, then "what is done justly" should be good
- Counter: Being put to death justly is not desirable (not good)
- Therefore: "The just is not entirely good"

The grammatical forms here are: "the just" (to dikaion, noun/adjective) and "justly" (dikaiōs, adverb).

## Usage

This topic is particularly useful for:
- Testing abstract claims by examining concrete instances
- Exposing hidden complexity in simple-seeming statements
- Arguing that general claims have exceptions

The example provided is instructive: it shows how the topic can reveal that even virtues like justice are not simple goods in all applications. The grammatical derivation from "just" to "justly" carries an expectation of consistency that can be exploited to show nuance.

Use when a term has multiple grammatical forms and you want to test whether a predicate consistently applies across them.

## Notes

This topic relies on the Greek system of grammatical inflection (ptōsis = "case" or "fall" of a word). While the specific mechanism is language-dependent, the underlying principle - testing claims across derived forms of a concept - applies broadly.
