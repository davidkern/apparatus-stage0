## Reference System

Aristotle uses **Bekker numbers** — the standard scholarly reference system:
- Format: `<page><column><line>` (e.g., 1397a7)
- Page numbers from Bekker's 1831 edition
- Column: `a` (left) or `b` (right)
- Line number within column

These are universal across translations.
