**Name:** Ordered Storytelling

**Definition:** Arrange data elements in a sequence that reveals meaning, rather than arbitrary orderings like alphabetical, so the structure itself communicates.

**Category Mapping:** Temporal / Comparative (meaningful sequence)

**How Tufte Articulates It:**
- "There are nearly always better sequences than alphabetical -- for example, ordering by content or by data values"
- Election supertable: "the rows are ordered so as to tell an ordered story about the elections"

**Examples Referenced:**
- Group percentages reordered from ABC to BCA (by ascending value)
- Election voting table with topical paragraphs and meaningful row order

**Source Type:** Explicit prose

**Limitations from Text-Only:** Can observe the textual argument; ordering is a structural property visible in text.
