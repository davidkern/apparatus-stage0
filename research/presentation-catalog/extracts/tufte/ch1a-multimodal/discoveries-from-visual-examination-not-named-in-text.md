These intents emerged from examining the figures but were not explicitly named by Tufte:

- **Encode Statistical Significance Visually** — The cancer maps use a five-level legend combining decile ranking with statistical significance testing. This is visible in the legend but not discussed as a design principle.

- **Use Geography as Organizing Frame** — The maps use familiar geographic shapes (U.S. outline) as a cognitive scaffold. Viewers' existing spatial knowledge aids interpretation. This is implicit in the data map form but not articulated.

- **Layer Information Hierarchically** — The Voyager 2 display stacks multiple related time-series with shared x-axis, creating implicit visual hierarchy. The train schedule uses station spacing proportional to actual distance. These compositional choices are visible but not theorized.

- **Show Simultaneity/Intersection** — Marey's train schedule shows where trains pass each other through line intersections. This specific communicative purpose (when do opposing movements coincide?) is demonstrated visually but only briefly mentioned.

## Notes on Tufte's Design Philosophy

Tufte's chapter establishes several overarching principles that shape how these intents are realized:

1. **Data Primacy**: The data should dominate the visual; design serves revelation, not decoration.

2. **Multivariate Orientation**: Excellence is "nearly always of a multivariate sort" — good graphics show relationships among multiple dimensions.

3. **Comparison as Foundation**: The bulleted list and examples return repeatedly to comparison as the fundamental graphical act.

4. **Skepticism of Summary Statistics**: Anscombe's quartet demonstrates that numerical summaries can deceive; graphics provide necessary evidential supplementation.

5. **Historical Continuity**: Tufte traces graphical forms through history (Lambert, Playfair, Marey) to show that fundamental graphical intents have remained stable even as data volumes have grown.
